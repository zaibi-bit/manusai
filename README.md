# SYNAPSE // AI Command Center

Personal hacker-themed dashboard: every AI one click away, plus a secure notes vault.

- **AI Arsenal** — animated launcher buttons for ChatGPT, Claude, Gemini, Grok, Perplexity, Copilot, Meta AI, DeepSeek, Le Chat, Qwen, Poe, HuggingChat
- **Secure Notes Vault** — notes saved in your browser (localStorage), with search, pin, export
- Zero backend, zero cost. Deploy anywhere static.

Live: deploy on Vercel or open `index.html`.
